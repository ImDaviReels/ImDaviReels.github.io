Política de privacidad

Última actualización: 25 de noviembre de 2026

Content Machine es una herramienta personal y no comercial que usa una única persona (el «propietario») para publicar vídeos en sus propias cuentas y consultar sus estadísticas. No tiene otros usuarios, no ofrece registro y no accede a cuentas de terceros.

1. Datos a los que accede y para qué

Solo con la autorización expresa del propietario, y solo sobre sus propias cuentas:

PlataformaPermisosUso
YouTube (Google) youtube.upload
youtube.readonly
yt-analytics.readonly		 Subir los vídeos que el propietario aprueba; leer los datos de su canal y de sus vídeos (identificadores, visualizaciones, «me gusta», comentarios) y sus estadísticas (tiempo de visualización, retención, compartidos, suscriptores ganados o perdidos).
Instagram (Meta) Publicación de contenido y estadísticas (insights) de la cuenta profesional Publicar los Reels aprobados; leer «me gusta», comentarios, seguidores y estadísticas de esas publicaciones (visualizaciones, alcance, guardados, compartidos, tiempo medio de visualización).
TikTok user.info.basic, video.upload, video.publish, video.list, user.info.stats Enviar los vídeos aprobados a la cuenta del propietario; leer sus vídeos públicos (visualizaciones, «me gusta», comentarios, compartidos) y las estadísticas de la cuenta (seguidores).

No se leen mensajes privados, listas de seguidores, datos de espectadores individuales ni información de otras personas. Las estadísticas que se usan son totales agregados que ofrece cada plataforma.

2. Dónde se guardan

  • Las autorizaciones (tokens) se guardan solo en el ordenador del propietario, con acceso restringido a su usuario. No se suben a ningún servidor, repositorio ni copia de seguridad.
  • Las estadísticas y los datos de las publicaciones se guardan en una base de datos local en ese mismo ordenador. Las copias de seguridad de esos datos (sin autorizaciones) se guardan en el almacenamiento personal en la nube del propietario.
  • Content Machine no tiene servidores propios.

3. Con quién se comparten

Con nadie. Los datos no se venden, no se ceden, no se usan para publicidad y no se transfieren a terceros.

Para producir los vídeos se usan servicios de IA (generación de texto, imagen, animación y voz). Esos servicios reciben únicamente el tema y las instrucciones creativas de cada vídeo. Nunca reciben datos obtenidos de las cuentas de Google, YouTube, Instagram o TikTok.

4. Datos de usuario de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de Uso limitado:

  • Los datos de Google se usan solo para las funciones descritas aquí: publicar en el canal del propietario y mostrarle sus propias estadísticas.
  • No se transfieren a terceros ni se usan para publicidad, para crear perfiles ni para entrenar modelos de inteligencia artificial.
  • Ninguna persona lee esos datos, salvo el propio propietario.

Content Machine usa los Servicios de la API de YouTube. Al usarla se aplican también las Condiciones del servicio de YouTube y la Política de privacidad de Google.

5. Conservación y eliminación

  • Las estadísticas se conservan mientras el propietario las necesite para analizar su canal, y puede eliminarlas en cualquier momento borrando la base de datos local.
  • Las autorizaciones pueden revocarse cuando se quiera: Google en myaccount.google.com/permissions, Meta en la configuración de «Aplicaciones y sitios web» de la cuenta, y TikTok en «Configuración y privacidad → Seguridad → Apps y servicios». Al revocarlas, la herramienta deja de poder acceder a los datos.

6. Menores

Content Machine no está dirigida a menores ni recoge datos de ellos.

7. Cambios

Si cambia el uso de los datos, se actualizará esta página y su fecha antes de aplicar el cambio.

8. Contacto

Para cualquier pregunta sobre esta política: mensaje directo a la cuenta de Instagram @imdavireels.

Summary in English

Content Machine is a personal, non-commercial tool used by a single owner to publish short videos to their own YouTube, Instagram and TikTok accounts and to read the analytics of those posts. It requests only the permissions listed above, stores tokens and analytics locally on the owner's computer, never sells or shares data, and never sends Google user data to AI services or any third party. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
